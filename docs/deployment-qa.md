已验证首次自动下载 Node 22 LTS 并校验 SHA-256、npm ci、生产构建、后台启动、健康检查，以及：

- 重复启动只有一个实例，并发启动由锁串行处理。
- 停止、重复停止、重启，状态查询无需 Node 出现在 PATH。
- 未修改代码时复用构建，修改代码后自动重建。

- 配置权限 600，运行目录权限 700。
- 未认证请求返回 401。
- 过期 PID 或其他进程 PID 不会误杀。
- 端口占用时启动明确失败，不误报健康、不终止占用进程。
- 停止与重启保留测试数据。
