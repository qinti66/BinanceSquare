# 墨金创作台 · Square Studio

中文币安广场多账号发布工作台，基于用户选定的墨金设计。个人本机使用。

## 启动

Node.js 20.19+，运行 npm install 后运行 npm run dev。
打开 http://localhost:4173 。启动命令同时运行 Vite 前端与 127.0.0.1:8787 本地 API。

## 已实现

- 帖子、文章、视频编辑；表情、话题、币种、链接；草稿内加粗/斜体/列表。
- 账号管理，展示名称仅本站使用，API Key 在本机 AES-256-GCM 加密保存，不回传明文。
- 按账号多选发布，逐账号成功/失败/不确定状态与本站发布历史；幂等重试避免重复发送。
- 编辑立即保存在浏览器，并自动同步到本机服务；草稿搜索、恢复、删除与导出。
- 图片上传、文章封面、视频封面自动提取；K线支持公开行情和图表图片发布。
- 明确区分演示工作区与真实工作区。初始示例不会向币安发送内容，真实发送需要用户确认。

## 当前能力边界

公开接口支持纯文本正文、图片短帖、带标题与单封面的文章、单视频。
草稿排版不会作为富文本提交；发布确认会提示。
K线以静态图片发布，不是币安原生可跳转挂件。
投票、资产/盈亏、交易记录等原生组件没有已核实的公开发布字段。
发布历史只包含本工作台发起的记录，不会同步其它客户端历史。
模拟测试已实现；未提供真实 API Key，因此线上发布尚未实测。

## 数据与备份

.data/ 包含数据库、媒体与加密主密钥，默认不提交到版本库。备份整个目录。
密钥与数据都在同一台电脑，加密不防范有完整本机文件权限的程序。
这是个人本地服务，没有公网登录或多租户隔离。发布静态前端不会同时部署本地后端。
